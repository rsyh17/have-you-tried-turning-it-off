A tiny Node program (stdlib only, no dependencies) that writes one funny line from a hopeless tech support agent to a desperate customer. The line twists the classic reboot advice into a sacred ritual, performed daily by tech priests since 1985, that fixes almost every computer — and none of the agent's own life choices.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry text to `out/entry.txt` (or to `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is not set). The output is byte-identical on every run and stays within the 1–199 character gate.
